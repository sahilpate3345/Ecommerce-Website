# Ecommerce-Website
A modern and responsive E-Commerce frontend website built using **HTML**, **CSS**, and **JavaScript**.  
This project includes product search, shopping cart functionality, checkout simulation, and purchase history tracking.

## 🚀 Features

- Responsive modern UI
- Product search functionality
- Add to Cart system
- Cart modal popup
- Dynamic total price calculation
- Checkout simulation
- Purchase history tracking
- Smooth scrolling navigation
- Interactive buttons and hover effects
